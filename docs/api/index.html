NX 小程序开发文档 wx.* 支持状态

wx.* API 支持状态

容器向页面注入全局 wx 对象。目前 42 个接口有真实行为， 18 个接口以空实现提供兼容。所有异步接口只支持回调风格，不返回 Promise。

异步回调：成功回调是 success，失败回调是 fail， 结束回调是 complete。回调在宿主主线程执行，可直接调用 setData。

网络

接口参数回调
wx.requesturl、method（GET/HEAD/POST/PUT/DELETE/PATCH）、data、header、timeout（毫秒，默认 60000）、responseType（text / arraybuffer）success({ data, statusCode, header, cookies }) / fail({ errMsg, statusCode, data, header }) / complete()
wx.getNetworkType—success({ networkType })，值为 wifi / ethernet / none
wx.onNetworkStatusChangecallback({ isConnected, networkType })网络类型变化时触发（约 2 秒轮询一次）；wx.offNetworkStatusChange 取消

GET / HEAD 会把 data 序列化为查询串，其他方法发送请求体； 未显式设置时自动补 Content-Type: application/json，data 为字符串时原样发送。responseType: "arraybuffer" 时 data 是 ArrayBuffer，可配合 Uint8Array 处理下载的二进制内容。 success 回调的 cookies 字段汇总了整条重定向链上的 Set-Cookie（键为 cookie 名），可用于登录态透传。

回调语义与微信一致：只要服务端返回了 HTTP 响应（包括 401 / 404 / 500），都会走 success， 由脚本按 statusCode 自行判断；fail 只在网络层失败时触发 （DNS、连接被拒、超时、TLS 等），且同样带上 statusCode、 data、header，errMsg 形如 "request:fail timeout"。

url 以 / 开头时按商店服务端地址解析，便于首页这类 “由服务端下发、内容随服务端更新”的小程序直接请求 /api/v1/miniapp-home。 

wx.request({
  url: 'https://example.com/api/list',
  method: 'POST',
  data: { page: 1 },
  success(res) {
    this.setData({ items: res.data.items });
  }
});

数据源（SMB）

容器内置 libsmb2，通过 wx.smb.* 访问局域网 SMB 共享 （Windows 共享、群晖、飞牛、极空间等）。连接与列目录为阻塞操作，在 工作线程执行；success / fail 回调在宿主主线程触发。 会话 id 随容器进程存活，不持久化到磁盘。

接口参数说明
wx.smb.connectserver、share、user、password、domain（可选）连接共享，success({ id }) 返回会话 id；fail({ errMsg })
wx.smb.listFilesid、path列目录，success([{ name, isDir, size }])；name 为共享内完整路径（/ 分隔）
wx.smb.streamUrlid、path返回本地 HTTP 代理播放地址（同步），可直接赋给 <video src>；代理端口全部占用时返回空串，应先判断再使用
wx.smb.scanid、path、maxDepth（可选，默认 4）、maxEntries（可选）、progress({ dirs, files })（可选）在宿主线程递归遍历目录树，一次回调返回全部文件条目 [{ name, isDir, size }]，比逐目录 listFiles 快很多；扫描中回调进度，配合 wx.smb.cancelScan() 可中途取消
wx.smb.cancelScan—取消正在进行的 scan，已收集的文件仍会通过 success 返回
wx.smb.disconnectid断开会话并释放资源
 
wx.smb.connect({
  server: '192.168.1.100',
  share: 'movies',
  user: 'admin',
  password: 'xxx',
  success(res) {
    var smbId = res.id;
    // 递归扫描视频文件：path 传目录，name 为完整路径
    wx.smb.listFiles({
      id: smbId,
      path: '/',
      success(files) {
        this.setData({ files: files.filter(function (f) { return !f.isDir; }) });
      }
    });
  },
  fail(err) {
    console.error(err.errMsg);
  }
});

// 播放：拿本地代理地址后交给 video（或 setData 到 src）
var url = wx.smb.streamUrl({ id: smbId, path: '/movies/a.mp4' });

播放走容器本地 HTTP 代理（127.0.0.1），支持 Range 请求（返回 206 Partial Content），由 MPV 直接拉取局域网数据流， 无需把整段视频读入内存。单次代理读取上限 4MB，MPV 会按 Range 分块请求。

媒体库索引（wx.media）

把“遍历目录 + 索引”下沉到宿主：索引按数据源落盘，目录修改时间未变化时 直接复用旧结果，后续进入只读本地索引，毫秒级返回。适用于影片数量多、 每次进入都要重扫的场景（如 SMB 影视库）。

接口参数说明
wx.media.scansourceId、id（SMB 会话 id）、root、maxDepth（可选，默认 4）、maxFiles（可选，默认 2000）增量扫描并写盘索引，只收录视频文件；success({ total }) 返回索引内文件总数
wx.media.librarysourceId、offset（可选）、limit（可选，0 表示全部）读取索引，success({ total, list: [{ name, size, subtitle? }] })；name 为共享内完整路径，subtitle 为同目录同名外挂字幕（.srt/.ass/.ssa/.vtt）的完整路径
 
// 先读库（有索引时立即返回），无索引或需要刷新时再触发增量扫描
wx.media.library({
  sourceId: source.id,
  success(page) {
    if (page.list.length) render(page.list);
    else wx.media.scan({
      sourceId: source.id, id: smbId, root: '/',
      success(res) { console.log('indexed', res.total); }
    });
  }
});

媒体

接口参数说明
wx.createVideoContext(id)id 对应 <video id="...">返回控制器：play() / pause() / stop() / seek(seconds) / requestFullScreen() / exitFullScreen() / setPlaybackRate(rate) / setVolume(0-100) / addSubtitle(url)
 
const ctx = wx.createVideoContext('demoVideo');
ctx.play();
ctx.seek(30);
ctx.setPlaybackRate(1.5);
ctx.setVolume(60);
ctx.requestFullScreen();
ctx.addSubtitle('https://example.com/movie.zh.srt');

<video> 支持的扩展属性：initial-time（起播秒数）、 playback-rate（倍速，1 为正常）、volume（0-100）、 subtitle（外挂字幕地址，支持 smb://会话id/路径 或 sdmc:/... 本地路径）、http-headers（鉴权直链的 Cookie）、 autoplay、loop、muted、poster、 object-fit。

事件：bindplay、bindpause、bindended、 bindtimeupdate、binderror、bindloadedmetadata、 bindwaiting、bindprogress、bindseekcomplete、 bindfullscreenchange。全屏时画面铺满内容区，按 B 退出并派发 bindfullscreenchange（{ fullScreen }）。

实际解码由 nxkit::MPVCore 完成。桌面构建默认关闭 NXKIT_WITH_MPV，需要安装 libmpv 并重新配置；未启用时 video 只显示 poster 与占位控制条，并派发 binderror。

小程序互跳

接口参数说明
wx.miniapp.launch(id)小程序 ID，或 { id }已安装则直接进入；未安装会先下载安装。返回布尔值表示是否已受理
wx.miniapp.listRecent()—返回最近使用的数组：[{ id, title, count, installed }]，按最近使用倒序
wx.miniapp.deviceId()—返回容器持久化的设备标识（首次生成后写入配置），用于服务端 UV 统计上报
 
const recent = wx.miniapp.listRecent();
wx.miniapp.launch(recent[0].id);

首页小程序就是靠这两个接口组织“推荐 / 最近使用”的；客户端启动时会先请求 /api/v1/miniapp-home 拿到首页小程序，再按版本安装运行。
