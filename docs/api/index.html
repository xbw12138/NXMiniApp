NX 小程序开发文档 wx.* 支持状态

wx.* API 支持状态

容器向页面注入全局 wx 对象。目前 38 个接口有真实行为， 18 个接口以空实现提供兼容。所有异步接口只支持回调风格，不返回 Promise。

异步回调：成功回调是 success，失败回调是 fail， 结束回调是 complete。回调在宿主主线程执行，可直接调用 setData。

网络

接口参数回调
wx.requesturl、method（GET/POST/PUT/DELETE）、data、headersuccess({ data, statusCode, header, cookies }) / fail({ errMsg }) / complete()
wx.getNetworkType—success({ networkType: "wifi" })

GET / HEAD 会把 data 序列化为查询串，其他方法发送 JSON 请求体； 未显式设置时自动补 Content-Type: application/json。 success 回调的 cookies 字段汇总了整条重定向链上的 Set-Cookie（键为 cookie 名），可用于登录态透传。 fail 回调的 errMsg 形如 "request:fail <curl 错误描述或状态码>"，例如 request:fail HTTP 401、request:fail curl code 35。 url 以 / 开头时按商店服务端地址解析，便于首页这类 “由服务端下发、内容随服务端更新”的小程序直接请求 /api/v1/miniapp-home。 

wx.request({
  url: 'https://example.com/api/list',
  method: 'POST',
  data: { page: 1 },
  success(res) {
    this.setData({ items: res.data.items });
  }
});

界面交互

接口参数说明
wx.showToasttitle、icon、duration绘制在屏幕底部，默认 2000ms
wx.showLoadingtitle全屏遮罩，需要手动关闭
wx.hideLoading—关闭 loading
wx.showModaltitle、content、showCancel、confirmText、cancelText宿主弹窗；success({ confirm, cancel })

wx.nextTickcallback下一帧执行
wx.vibrateShorttype桌面/主机暂无振动能力，空实现
wx.canIUseschema按当前已注入能力返回布尔值

媒体

接口参数说明
wx.createVideoContext(id)id 对应 <video id="...">返回控制器，支持 play() / pause() / stop() / seek(seconds)；requestFullScreen / exitFullScreen 为空实现
 
const ctx = wx.createVideoContext('demoVideo');
ctx.play();
ctx.pause();
ctx.seek(30);

实际解码由 nxkit::MPVCore 完成。桌面构建默认关闭 NXKIT_WITH_MPV，需要安装 libmpv 并重新配置；未启用时 video 只显示 poster 与占位控制条，并派发 binderror。

小程序互跳

接口参数说明
wx.miniapp.launch(id)小程序 ID，或 { id }已安装则直接进入；未安装会先下载安装。返回布尔值表示是否已受理
wx.miniapp.listRecent()—返回最近使用的数组：[{ id, title, count, installed }]，按最近使用倒序
wx.miniapp.deviceId()—返回容器持久化的设备标识（首次生成后写入配置），用于服务端 UV 统计上报
 
const recent = wx.miniapp.listRecent();
wx.miniapp.launch(recent[0].id);

首页小程序就是靠这两个接口组织“推荐 / 最近使用”的；客户端启动时会先请求 /api/v1/miniapp-home 拿到首页小程序，再按版本安装运行。

数据缓存

接口说明
wx.setStorageSync(key, data)写入并同步落盘，值为 JSON 字符串
wx.getStorageSync(key)读取并反序列化，不存在返回 ""
wx.removeStorageSync(key)删除单个键
wx.clearStorageSync()清空当前小程序缓存
wx.setStorage / getStorage / removeStorage / clearStorage回调风格的异步版本
wx.getStorageInfoSync(){ keys, currentSize, limitSize }
wx.getStorageInfo()异步返回同样的结构

缓存按小程序包隔离，保存在 miniapp/storage/<hash>.json。

路由

接口参数行为
wx.navigateTourl 可带 query压栈并触发 onHide / onLoad / onShow
wx.navigateBackdelta出栈并触发 onUnload
wx.redirectTourl替换当前页
wx.reLaunchurl清空页面栈后打开目标页
 
wx.navigateTo({ url: '/pages/detail/detail?id=42' });

// detail.js
Page({
  onLoad(query) {
    this.setData({ id: query.id });
  }
});

兼容占位接口

以下接口存在但不会产生效果，用于让微信代码平滑运行：

setNavigationBarColor、showNavigationBarLoading、 hideNavigationBarLoading、setKeepScreenOn、 setPreferredFramesPerSecond、reportAnalytics、 reportEvent、onNetworkStatusChange、 onAppShow、onAppHide、onError、 onUnhandledRejection、pageScrollTo 及对应的 off* 接口。

全局对象

名称说明

App(options)注册应用级对象，支持 onLaunch / onShow / onHide
getApp()返回 App 实例
getCurrentPages()返回页面路径数组
setTimeout / setInterval / clearTimeout / clearInterval由容器每帧驱动
console.log / info / warn / error写入宿主日志
