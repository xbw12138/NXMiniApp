NXMiniApp 小程序开发文档

NXMiniApp 是运行在 Nintendo Switch 与桌面端的小程序容器。页面用 WXML 描述结构、WXSS 子集描述样式， JS 由 QuickJS 常驻执行，通过 setData 增量驱动重绘；最终由 Yoga 排版、NanoVG 原生绘制， 不经过 webview。

先读这一条：这是微信小程序的一个可运行子集，不是完整实现。当前没有 webview、 自定义组件、video / canvas / map、npm 构建与开发者工具。 未列出的能力请以本文档为准，不要直接按微信官方文档推测行为。

最小可用小程序

包内必须有 app.json，页面三件套缺一不可（空的 .wxss 也要建文件）。

hello/
├── app.json
├── app.js
├── app.wxss
└── pages/index/
    ├── index.wxml
    ├── index.wxss
    └── index.js
// app.json
{
  "pages": ["pages/index/index"],
  "window": { "backgroundColor": "#141518" }
}

<!-- pages/index/index.wxml -->
<view class="page">
  <text class="title">{{title}}</text>
  <text class="count">count = {{count}}</text>
  <button bindtap="onAdd">点我 +1</button>
</view>

/* pages/index/index.wxss */
.page { flex-direction: column; justify-content: center; align-items: center; }
.title { color: #F5F6F7; font-size: 44rpx; font-weight: bold; }
.count { color: #0FDC78; font-size: 28rpx; margin: 16rpx 0; }

// pages/index/index.js
Page({
  data: { title: "Hello NXMiniApp", count: 0 },
  onAdd() {
    this.setData({ count: this.data.count + 1 });
  }
})

本地预览

# 1. 构建桌面客户端（在 client/ 目录）
cmake -S . -B build_desktop -DPLATFORM_DESKTOP=ON \
  -DCMAKE_POLICY_VERSION_MINIMUM=3.5 -DPYTHON_EXECUTABLE=$(which python3)
cmake --build build_desktop --target miniapp -j 8

# 2. 启动服务端（在仓库根目录，需要 Docker）
docker compose up --build -d

# 3. 运行：默认进入商店启动器
cd build_desktop/apps/miniapp && ./miniapp

# 或跳过商店，直接预览本地包
NXKIT_MINIAPP_DEV=<repo>/client/resources/miniapps/playground ./miniapp

没有开发者工具与 console 面板；调试手段是启动日志与页面中央的红色错误文字。
