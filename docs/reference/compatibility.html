与微信小程序的差异

多数页面逻辑可以复用，但渲染模型、交互方式与可用 API 仍然是子集。下面每一条都会影响迁移结果。

迁移检查清单

  1. 补齐 app.js / app.wxss（可选），页面路径写进 app.json 的 pages。
  2. 把依赖自定义组件、template / import 的结构改写为内置标签。
  3. wx:elif / wx:else 与 wx:for 可以直接使用；wx:key 可保留但无 diff 作用。
  4. bind:tap / catchtap 可以直接使用；bindtap 会沿祖先冒泡，catchtap 终止冒泡。
  5. 把未列出的 wx.* 调用替换为已支持接口，或加上 wx.canIUse 判断。
  6. 按 样式章节 清理伪类、动画、渐变、媒体查询与子代选择器。
  7. 布局默认是 column；需要横排时显式写 flex-direction: row。
  8. 按 1280×720 重新排版；超出一屏的内容放进 scroll-view。
  9. 远程图片改为包内资源；image 的 mode 支持 scaleToFill / aspectFit / aspectFill。
  10. textarea 目前是单行输入法，多行编辑需要拆成多个 input。

设计建议

  • 焦点即光标：所有可交互控件都参与方向键导航，布局要保证焦点顺序自然。
  • 一屏一主题：内容多时用 scroll-view，并保证可聚焦元素能把视口带到目标位置。
  • 用色块表达层级：背景、边框、圆角与阴影是最稳定的视觉手段。
  • 尺寸按 rpx 设计：按 750 宽设计稿换算，心里记住 750rpx ≈ 640 逻辑像素。
