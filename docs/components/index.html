组件总览

容器内置 22 类标签。所有组件都由 Yoga 排版、NanoVG 绘制，不依赖 HTML。 未识别的标签会自动降级为 view。

view / scroll-view

默认 flex-direction: column。scroll-view 通过 scroll-y="{{true}}" 或 scroll-x="{{true}}" 开启滚动； 内容超出时由焦点导航自动滚动到可见区域。鼠标左键与触摸点击会命中渲染树， 触发对应节点的 bindtap 并沿祖先冒泡（catchtap 终止冒泡）。 鼠标滚轮暂未接入。 

<scroll-view class="panel" scroll-y="{{true}}" style="height: 100%;">
  <view class="card">...</view>
</scroll-view>

text / rich-text

text 支持 {{}} 插值与嵌套换行；默认继承父级颜色。 rich-text 只读取 nodes 字符串，当前降级为纯文本：剥离 HTML 标签、 还原常见实体，不渲染内联样式与图片。 

<text>共 {{items.length}} 项</text>
<rich-text nodes="&lt;b&gt;标题&lt;/b&gt;，正文"></rich-text>

image / icon

image 读取包内路径（以 / 开头）或启动器缓存的本地文件； 支持 scaleToFill（默认）、aspectFit、aspectFill。 远程 URL 暂不下载，会显示占位。 

<image src="/images/logo.png" mode="aspectFit" class="logo"/>

icon 为原生绘制：type 可取 success / info / warn / waiting / cancel / clear / search / download， size 为 rpx 数值。

button / navigator

button 默认使用主题绿色，可用 class 或内联样式覆盖。 与 view 一样通过 bindtap 触发事件。 navigator 在激活时直接跳转：默认 navigateTo， open-type 可取 redirect / reLaunch。 

<button bindtap="onAdd">+1 计数</button>
<navigator url="/pages/detail/detail?from=list">打开详情</navigator>

input / textarea

激活后调用系统输入法。value 与 placeholder 支持数据绑定， bindinput 在输入确认时触发，bindconfirm 同时触发。

限制：textarea 目前复用单行输入法，不能真正换行； 多行仅体现为更高的默认高度。 
<input class="input" value="{{nick}}" placeholder="昵称"
       bindinput="onInput" bindconfirm="onConfirm"/>

switch / checkbox / radio

三者都是原生绘制，A 键切换状态并派发 change，事件对象 detail.value 为布尔值。选中状态保存在页面内，不会自动回写 data，需要在事件里自行 setData。 radio 通过 name 分组，同组只保留一个选中项。 

<switch checked="{{enabled}}" bindchange="onSwitch"/>
<checkbox checked="{{accept}}" bindchange="onCheckbox"/>
<radio-group>
  <radio name="plan" value="a" checked="{{plan==='a'}}" bindchange="onRadio"/>
  <radio name="plan" value="b" checked="{{plan==='b'}}" bindchange="onRadio"/>
</radio-group>

slider / progress

slider 支持 min / max / step / value；方向键左右调整，A 键按 step 递增，触发 change。progress 读取 percent（0–100）， 可选 activeColor / backgroundColor。 

<slider min="0" max="100" step="5" value="{{volume}}" bindchange="onSlider"/>
<progress percent="{{volume}}" activeColor="#22c55e"/>

swiper / swiper-item

swiper 只构建当前项的子树，autoplay 与 interval（毫秒）驱动自动轮播，底部绘制指示点。 暂不支持 bindchange、纵向轮播与手势滑动。 

<swiper autoplay="{{true}}" interval="{{3000}}" class="swiper">
  <swiper-item><view class="slide">第一屏</view></swiper-item>
  <swiper-item><view class="slide">第二屏</view></swiper-item>
</swiper>

video

支持 src、poster、autoplay、loop、 muted、controls 与 object-fit（contain / cover / fill）。点击画面或按 A 键播放/暂停， 底部控制条显示进度、时间与状态。

播放后端是 nxkit::MPVCore：

  • Switch 构建默认开启 NXKIT_WITH_MPV，可加载包内文件路径或 HTTP(S) 地址。
  • 桌面构建默认关闭；需要安装 libmpv 后以 -DNXKIT_WITH_MPV=ON 重新配置。
  • 未启用 MPV 时只显示 poster 与占位控制条，点击播放会提示 “视频播放需要启用 libmpv 的构建”，不会伪造播放。
<video id="demoVideo" class="video" src="/videos/demo.mp4" poster="/images/logo.png"
       autoplay="{{false}}" loop="{{true}}" muted="{{true}}" controls="{{true}}"
       bindplay="onVideoPlay" bindpause="onVideoPause"
       bindended="onVideoEnded" bindtimeupdate="onVideoTime"
       binderror="onVideoError"/>

脚本侧通过 wx.createVideoContext(id) 控制播放：

const ctx = wx.createVideoContext('demoVideo');
ctx.play();
ctx.pause();
ctx.seek(30);
ctx.stop();
限制：全局只有一个 MPV 实例，同一时间只播放一个 video； 视频直出层不参与 NanoVG 合成，被 scroll-view 裁剪或完全移出屏幕时暂停绘制。

form / label / checkbox-group / radio-group / block

这些标签只承担容器语义：form、label 与分组标签会正常排版子节点， 但不会汇总提交；block 不产生节点，只展开子节点。 表单提交建议在按钮的 bindtap 里手动读取页面状态。

组件实现位于 client/apps/miniapp/source/miniapp_view.cpp 与 layout.cpp。
