安装与更新

  1. 下载最新版 .nro 文件，重命名为 NXMiniApp.nro。
  2. 拷贝到 Switch TF 卡的 /switch/ 目录（旧版本直接覆盖即完成升级）。
  3. 通过 Homebrew 菜单启动，容器会自动连接商店检查小程序更新。
  4. 下载后可对照页面上展示的 SHA-256 校验文件完整性。
