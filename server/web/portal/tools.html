01应用商店启动器

updater.nro 在 Switch 上提供完整的商店界面：应用卡片墙、分类筛选、详情面板与一键安装。 它还负责容器更新——先备份旧 NRO，多段并行下载新版本，校验通过后替换，失败自动回滚。

02SwLink 画面串流

把 Switch 的画面和声音投到 Mac，USB 直连或同一 Wi-Fi 无线串流

SwLink 是随系统启动的模块（sysmodule），通过系统录制接口 grc:d 取 720p30 H.264 画面与 48kHz 立体声。 电脑端 SwLink.app 负责解码与显示，支持独立窗口、全屏与静音。

连接方式端口适用场景
USBVID:PID 16C0:27DA延迟最低，传大文件首选
Wi-Fi 串流TCP 12345不想插线，建议 5GHz
Wi-Fi 发现UDP 12346自动发现局域网主机，免手填 IP
Wi-Fi 文件TCP 12347无线读写 SD 卡，与串流互不影响
  • 独立窗口：纯画面弹出到副屏，可缩放、可全屏
  • 全屏：主窗口全屏；纯画面满屏请用独立窗口
  • 按需采集：首次连接才打开 grc:d，待机时不影响休眠
  • 唤醒自愈：休眠唤醒后自动重建监听，不需要重启主机
只有支持系统录屏（长按截图键）的游戏才有画面；主菜单与设置界面不产生录制输出。建议安装 dvr-patches 解锁全部游戏。

03SD 卡文件传输

USB 与 Wi-Fi 都能读写 Switch 的 SD 卡，像本地文件夹一样操作

文件通道与串流完全分开：USB 走文件接口，Wi-Fi 走独立的 TCP 12347。 同一套 SwlinkFtHeader 协议，40 字节请求/响应头 + 负载，按 512KB 分块。

浏览与下载

按表头排序、搜索过滤、多选（⌘/Shift）、整目录递归下载。

上传

支持整个文件夹拖入窗口，直接写入当前目录；上传前可确认覆盖。

管理与容量

新建目录、重命名、批量删除；底部显示 SD 已用/剩余容量进度条。

  • 右键菜单：打开 / 下载、重命名、复制路径、删除
  • 快捷键：⌘A 全选、⌘R 刷新、Del 删除、Enter 打开、Backspace 上级、↑↓ 选择
  • 传输中：显示速度与剩余时间，可随时取消；失败会停在当前项并提示原因
大文件优先插 USB；Wi-Fi 文件通道与串流共用同一条无线链路，4~10 MB/s 属正常范围。

04安装与升级

推荐从商店安装，之后全程一键升级

方式一：商店内安装（推荐）

打开容器→应用商店→SwLink→安装→重启主机

商店里出现新版本时，在「更新」页直接升级，不用再拔 SD 卡。

方式二：手动安装

下载安装包解压到 SD 卡根目录（目录已建好）：

curl -LO https://raw.githubusercontent.com/xbw12138/SwitchTools/main/dist/swlink-sysmodule-sd.zip
unzip swlink-sysmodule-sd.zip -d /Volumes/<你的 SD 卡>

装完后应存在：

SD:/atmosphere/contents/00FF0000A53B5A57/
├── exefs.nsp
├── toolbox.json
└── flags/boot2.flag

重启主机，或在 Tesla 菜单 → Sysmodules 里启用。开机后 SD 卡根目录会生成 SwLink.log；没有日志说明模块未加载。

与 SysDVR 等同样占用 usb:ds 的系统模块冲突，请勿同时启用。

05macOS 客户端

免编译直接下载，内置 SDL2 / libusb / ffmpeg

下载 SwLink.app 下载 swlink-cli 源码与教程 
unzip swlink-app-macos.zip
xattr -dr com.apple.quarantine SwLink.app   # 首次运行需放行
open SwLink.app
  • USB 连接：数据线直插 Mac 机身口，不经过 hub / 扩展坞
  • 无线连接：点「无线连接」，选自动发现的设备；也可手填 IP 与端口
  • 同时只能一个客户端：SwLink.app 与 swlink-cli 不能同时占用 USB 设备
macOS 12 及以上；Apple Silicon 需安装 Rosetta。未做 Apple 公证，首次打开被拦截时右键 → 打开。

06命令行 swlink-cli

批量操作 SD 卡、推送 NRO，适合脚本与自动化

免编译版本已内置 libusb，解压后两个文件必须放在同一目录：

curl -LO https://raw.githubusercontent.com/xbw12138/SwitchTools/main/dist/swlink-cli-macos-x64.zip
unzip swlink-cli-macos-x64.zip -d swlink-cli
xattr -dr com.apple.quarantine swlink-cli

./swlink-cli/swlink-cli ls /switch
命令说明
ls [路径]列出目录，默认 /
get <远端> <本地>下载文件；远端是目录时递归下载
put <本地> [远端]上传文件或目录；目标是已存在目录则拼文件名
nro <本地.nro> [远端]写入 NRO，默认 switch/<文件名>
mkdir / rm --dir / mv建目录、递归删除、重命名
df显示 SD 卡总容量与剩余空间
 
# 看容量与目录
./swlink-cli df
./swlink-cli ls /switch

# 推送 NRO(之后在 hbmenu 的 switch 目录里运行)
./swlink-cli nro ./hbmenu.nro

# 递归上传 / 下载整个目录
./swlink-cli put ./payload /switch/payload
./swlink-cli get /switch/payload ./downloaded

# 清理
./swlink-cli rm /switch/payload --dir
  • 远端路径统一以 / 开头（/ 即 SD 卡根）
  • 退出码 0 成功、1 失败；进度条写 stderr，可与 2>/dev/null 分离
  • CLI 只走 USB：没有 --wifi 参数，SD 卡读写必须插线
  • 大文件按 512KB 分块；传输中不要拔线，半截请求会让端点停滞数秒

07配套 Skill

把 SwLink 的使用规范交给 AI，直接用自然语言操作 SD 卡与排查连接

swlink-cli Skill 描述了完整的命令语义、路径规则、协议约束与排障流程。装进支持 Skill 的 IDE （Trae / Claude Code 等）后，AI 能按规范帮你列出目录、批量上传、推送 NRO， 并在「找不到设备」时按顺序排查数据线、sysmodule 与端口占用。

安装

# 仓库内路径
git clone https://github.com/xbw12138/SwitchTools.git
mkdir -p your-project/.trae/skills/swlink-cli
cp SwitchTools/.trae/skills/swlink-cli/SKILL.md \
   your-project/.trae/skills/swlink-cli/

"列出 SD 卡根目录，找出所有大于 100MB 的文件"
"连不上 Switch，按 skill 的排查流程帮我定位"

08常见问题

现象原因与处理
未找到设备 16C0:27DA模块未启动 / 充电线 / 被占用：先看 SD 卡有没有 SwLink.log，换数据线，退出 SwLink.app
claim_interface: Access deniedSwLink.app 占着 USB，退出后重试
文件页报「连接文件通道超时」设备端过旧，没有 TCP 12347；升级到 1.2.0 以上
一直「等待画面」停在主菜单或该游戏不支持录制；进入游戏画面等待 10 秒
锁屏/唤醒后卡死旧版监听线程空转；1.1.0 起已修复，唤醒后自动重建监听
开机后没有 SwLink.log固件与 NPDM 不匹配；使用 1.1.0 以上安装包，或按固件版本重编
开机黑屏关机拔卡，删除 atmosphere/contents/00FF0000A53B5A57 整个目录即可恢复
