Nintendo Switch / 桌面端小程序容器

把小程序带进 Switch

NXMiniApp 是一个免 webview 的小程序容器：用 WXML 描述结构、WXSS 子集描述样式， JS 由 QuickJS 常驻执行，经 Yoga 排版、NanoVG 原生绘制。 写一次微信小程序风格的代码，就能在 Switch 上以原生性能运行。

容器能力

覆盖小程序开发的常用场景，行为以开发文档为准

22 类内置标签

view、text、image、button、scroll-view、swiper、video 等常用组件开箱即用，未知标签自动降级为 view。

模板与数据绑定

支持 {{ }} 插值、wx:if / wx:for 指令、模板表达式，通过 setData 增量驱动界面重绘。

QuickJS 常驻运行时

每个页面独立 JS 上下文，支持 Page / App、async / await、Promise 与定时器，生命周期完整。

36 个 wx.* API

网络、存储、导航、振动、系统信息等接口真实可用，另有 18 个兼容占位接口便于迁移。

视频播放

内置 video 组件，支持播放 / 暂停 / 进度事件，在启用 MPV 的构建上可真实播放视频流。

商店式启动器

商店与启动器一体，HOME 菜单即开即玩；自动检查更新，上架后全平台用户即时可见。

Switch 应用商店启动器

独立 updater.nro：原生卡片墙商店 + 容器一键更新，不依赖电脑

装一次，之后全程免插线

updater.nro 在 Switch 上提供完整的商店界面：应用卡片墙、分类筛选、详情面板与一键安装。 同时负责容器更新——先备份旧 NRO，多段并行下载新版本，校验通过后替换，失败自动回滚。

四步上架你的小程序

投稿免登录，管理员审核通过后自动出现在商店

按子集开发
参照开发文档编写页面：WXML 结构 + WXSS 样式 + JS 逻辑，入口配置在 app.json。
打包
把整个目录（含 app.json 于包根）压缩为 .zip 或 .nxpkg，大小不超过 32MB。
在线投稿
打开投稿页填写名称、简介并上传安装包，无需注册账号。
审核上架
管理员在后台审核内容，通过后设为已发布，Switch 商店内即刻可下载体验。

用 AI 辅助开发

配套 Skill 已内置容器全部子集规范，让 AI 帮你写对的小程序

nxminiapp-dev 开发技能

把 Skill 装进 Trae / Claude Code 等支持技能的 IDE，AI 即可按容器规范工作： 只使用 22 类可用标签与 36 个 wx.* API，按 app.json 规范组织目录， 自动完成打包与投稿，避开 webview / canvas 等不支持的特性。
